# Estúdio Zenia Santos

Landing page responsiva em Vue 3, Composition API, Vite e Tailwind CSS v4.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Personalização antes de publicar

- Edite `src/data/site.js` para informar nome, WhatsApp, endereço, cidade e horário corretos.
- Confirme os serviços em `src/data/site.js`; a lista atual é uma sugestão inicial.
- Troque as imagens ilustrativas por fotos próprias com autorização.
- Atualize o link do Instagram em `src/components/SiteFooter.vue`.
- Revise os textos para refletirem com precisão a história profissional.

## Estrutura

- `src/components/`: header, hero, trajetória, serviços, portfólio, contato e rodapé.
- `src/data/site.js`: informações do salão e conteúdo das listas.
- `src/assets/main.css`: Tailwind, identidade visual e estilos responsivos.
